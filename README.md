# 古风小生文案变装器 · Gufeng Xiaosheng Transformer

一键把你的现代文案「变身」成古风小生风格，自带文人雅士的气质加成。

---

## 项目简介

写小红书文案写累了？用这个工具把你的大白话「雅化」一下：

- **古风词汇库**：收录大量文言词汇、典故、诗词金句
- **文风调节**：可选「温润如玉」或「狂放不羁」两种风格
- **即时预览**：改一个字都能看到效果，所见即所得
- **一键复制**：生成后直接复制，发笔记就用它

适合想写古风文案但文笔不够的同学，或者单纯想找点乐子 😄

---

## 使用方法

1. 打开 `index.html`（双击即可在浏览器运行）
2. 输入你想「雅化」的现代文案（支持多篇）
3. 选择风格模式：温润如玉 / 狂放不羁
4. 点击「开始变装」
5. 预览结果，一键复制到剪贴板

---

## 技术栈

- **纯 HTML/CSS/JS**，零依赖，单文件部署
- **本地替换引擎**，无 API 调用
- **古风词库**：文言词汇 + 诗词典故 + 雅称替代
- **响应式布局**，移动端友好

---

## 本地运行

```bash
# 方式一：直接打开
双击 index.html 即可

# 方式二：本地服务器（推荐）
python -m http.server 8080
# 访问 http://localhost:8080
```
